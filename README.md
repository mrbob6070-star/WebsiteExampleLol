# WebsiteExampleLol

A simple one-page website, ready to deploy on [Vercel](https://vercel.com) straight from GitHub.

## 🚀 Deploy it

1. Push this folder to a new GitHub repo (see "Upload to GitHub" below).
2. Go to [vercel.com](https://vercel.com) → sign in with GitHub.
3. Click **Add New → Project**, pick this repo, click **Deploy**.
4. That's it — no build settings needed, this is a plain HTML site.

## ✏️ Edit it

- **Text & content:** open `index.html`, change the words between the tags.
- **Colors & fonts:** open `style.css`, edit the values at the very top under `:root { ... }`.
- **Add a project card:** copy one `<article class="card">...</article>` block in `index.html` and paste it again with new content.

Every time you edit a file on GitHub and commit, Vercel automatically redeploys the live site within about a minute.

## 📁 Files

- `index.html` — the page content
- `style.css` — all the styling/colors/fonts
- `script.js` — one small script (auto-updates the footer year)
